# swengineering_project
작업별 링크·할 일·메모를 관리하는 나만의 시작 웹페이지

## 로컬 실행

React 앱은 저장소 안의 `start-react-setup/`에 있습니다. 저장소 루트에서 다음 명령을 실행하세요.

```cmd
cd start-react-setup
npm ci
npm run dev
```

터미널에 표시되는 Local 주소를 브라우저에서 엽니다. PowerShell에서 `npm.ps1`이 차단되면 `npm.cmd`로 실행하세요.

검사 명령과 컴포넌트 연결 방법은 [앱 README](start-react-setup/README.md)를 참고하세요.

## 배포 경로

Vercel에 연결할 경우 Root Directory를 `start-react-setup`, Build Command를 `npm run build`, Output Directory를 `dist`로 지정합니다. 이 안내는 경로 기준이며 실제 배포 설정이나 연결 상태를 변경한 것은 아닙니다.
