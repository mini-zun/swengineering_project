## 발견 사항과 수정

1. **P2 — 테마 선택창 닫기 버튼 대비 부족**: ThemeDialog는 레이아웃 밖(App)에 있으므로 `.retro-desktop-layout button.primary`가 적용되지 않는다. 전역 primary 규칙에 의해 배경 `#17172b`와 글자 `#4e7c7c`가 적용되어 선언 색상 대비는 약 3.77:1이다. 테마 루트 범위의 선택창 전용 normal/hover 규칙을 추가했다. 기본 대비는 약 9.67:1이며 두 상태 모두 4.5:1 이상인지 정적 회귀 검사한다. 이는 실제 브라우저 computed style 측정과 구분한다.
2. **병합 전 확인 필요 — PR #30과 충돌**: 렌더러 import·등록 및 문서 네 곳에서 연속 병합 충돌을 재현했다. 레트로 추가 위치를 메모보드와 분리하여 두 테마 등록·문서를 함께 유지하도록 수정했다. 기능·저장 형식은 변경하지 않았다.
