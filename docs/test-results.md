## Chrome 수동 확인

`http://localhost:5173/`에서 확인했습니다. Chrome 실제 버전은 수집하지 못했습니다. 도구 캡처에는 919×810·1536×816 창이 나타났으나, 요구된 1280×720·1920×1080 뷰포트 검증은 완료하지 못했습니다.

- 바로가기 등록창 열기·닫기, 닫은 뒤 기존 빈 목록 유지.
- `javascript:alert(1)` 등록 시 HTTP·HTTPS만 허용한다는 오류 표시와 입력값 유지. 링크는 등록되지 않았습니다.
- 달력의 다음 달 이동, 2027년 1월에서 이전 달인 2026년 12월 이동, 오늘 버튼으로 2026년 11월 복귀와 11일 강조 표시.
- 하단 문구가 `???`로 깨지는 것을 확인해 기존 저장 안내 문구로 복구했습니다. 복구 후 브라우저 재확인은 하지 않았습니다.

검증 중 접근성 좌표 오류·창 가림·입력 감지로 중단된 조작은 통과로 기록하지 않았습니다. 사용자 요청으로 브라우저 접근을 종료했으며 실제 사용자 내용이 담긴 화면 캡처는 저장하거나 공개하지 않았습니다.
